- 版本：0.6.0，标签 `v0.6.0`，提交 `389efddfee6396e34125b072698f7031b0f26f5e`
- 引擎构建 ID：`79b5cf3f8f85a4f1b00189f247f1a12cee345f5601ab93e302e50d205181a164`；目标图评分构建 ID：`147b918dc0232a92a4232661db7ed083bbeca340b9cdb721c17ad1337a014eff`
- 日期：2026-11-06。npm 仓库：`@livemira/engine`、`@livemira/ui`、`@livemira/target-rating`（`npm/` 中是同样三个包的离线 tarball）。
- 性质：0.6.0 正式版，基于 0.5.1。识别与跟踪算法不变；本版处理"页面隐藏、相机授权、视频保留"这类会话层的问题。
- 大小（压缩前）：引擎 125 KB，相机界面 35 KB，目标图评分 47 KB。

## 相对 0.5.1

- **页面隐藏时挂起，而不是结束**：引擎新增 `suspend()`、`resume()`、`isSuspended`；相机界面的会话同样有 `suspend()`、`resume()` 与状态字段 `isSuspended`。挂起时所有视频暂停（无声音），识别与绘制暂停，相机轨道关闭（`enabled = false`），识别 Worker 持有的轨道也一并关闭并丢弃收到的帧；引擎、已编译的照片和已加载的视频保留，画面中的目标以新的原因 `'suspended'`（`targetLost`）报告丢失。回到前台后自动恢复并重新识别。
- **`isStoppedWhenHidden` 默认值变化**（行为变化）：不设置时页面隐藏即挂起（引擎模块较旧、不支持挂起时仍然停止运行）；`true` 保持 0.5 的行为（结束运行并提示）；`false` 不处理。依赖"页面隐藏必定结束运行"的宿主需要显式传 `true`。
- **视频按运行保留**：照片第一次被识别时才请求它的视频，之后在本次运行内一直保留。目标丢失后再次识别、在照片之间切换都不会重复请求，其他照片的下载也不会被中断。`stop()`（含退出与 `dispose()`，也包括授权提示、准备或下载进行中）取消全部下载、释放全部视频，之后到达的结果被忽略。
- **同一时间只播放一个视频**：引擎新增可选的 `media.selectTarget(targetId | null)`；会话选中当前识别到的照片，其他照片保留的视频保持暂停，声音与"重新加载视频"作用于被选中的视频。单独使用引擎、不调用它时，画面中的每张照片仍播放自己的视频。
- **等待相机授权的界面**：`readiness` 只统计真实的准备工作（照片的完成比例），引擎加载完成前为 `null`；等待授权不再卡在一个虚构的百分比上。加载卡片的圆环只在有实际进度时填充，其他等待（加载识别组件、等待授权）改为转动，圆环里不再显示百分数；相机未打开时，顶部显示一行简短提示"请允许使用相机"，尽量减少被浏览器授权弹窗遮挡。
- **相机隐私修复**：
  - 在授权提示尚未结束时停止运行，之后才批准的相机流现在会被立即关闭（此前没有人再去关它）；
  - 页面隐藏不再让相机轨道保持工作；
  - 页面一打开就处于隐藏状态（浏览器不会为这个初始状态触发 `visibilitychange`）时，同样挂起。
- **文案调整**（中英文）：相机提示"请允许使用相机"，视频状态"正在准备视频…""正在加载视频 N%"，丢失提示"照片已移出画面"。按这些文字写断言的测试，或复制了这些文字的 `messages` 覆盖需要随之调整。
- 目标图评分的文档改为 npm 包 `@livemira/target-rating`（同时仍有离线 tarball）；发布包的清单 `npmRegistry` 列出三个包。
- 发布工具：集成指南与本说明的模板在仓库的 `release-src/`，更新日志与 NOTICE 在仓库根目录，指南只保留 `documentation/` 一份；发布包的 `demo/` 现在也带有目标图评分模块；生成发布包时会检查所有 Markdown 的相对链接。示例的照片与视频沿用 0.5.1 发布包里的那一套。

## 限制

- 挂起关闭的是相机**轨道**，不是相机；浏览器的相机指示灯是否熄灭取决于浏览器。要释放相机请 `stop()`。
- 隐藏与授权相关的改动由单元与集成测试覆盖，发布者已确认手机上的整体体验改善；没有为本版重新跑更大范围的设备矩阵。安卓与应用内浏览器的兼容性仍未逐一验证。
- 此前版本的限制仍然适用：边下边播在桌面 WebKit 测试版中无法验证，以 iPhone 真机为准。
