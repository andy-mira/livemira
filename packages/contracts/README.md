# Contracts 0.1.0

[English](README.md) | [简体中文](README.zh-CN.md)

Shared types and validators for the LiveMira modules. Import `@livemira/contracts`. Run `npm ci && npm test` from the repository root. This package is private (it is not published to npm); `private` is a publishing safeguard, not a license restriction. TypeScript 5.9.3 is the only build dependency; the npm lock records its integrity. Node 25.9.0 and npm 11.12.1 are the measured toolchain; the declared engine range is not a tested compatibility claim.

## Conventions

- Matrices are row-major, multiplying column vectors on the left. Homography maps original target pixels into standard unmirrored tracking pixels. `normalizeHomography` uses h22 when safe, otherwise a maximum-absolute-element gauge; singular or nonfinite matrices reject.
- Raster feature centers are integer coordinates 0..width-1. Physical/render corners are **edges** (0,0),(width,0),(width,height),(0,height), in target order. Do not reorder corners in screen space. Fixtures that sample corners at width-1 must convert when forming a `TrackingResult`.
- All times are microseconds. `observationTimeUs` is the session-monotonic **mapped observation time**, never raw media time. Unavailable exposure or clock uncertainty is null. `mappedObservationTimeUs` is optional for older producers; arrival is only a receipt measurement. `imageIdentity` identifies duplicate content where source timestamps alone do not.
- A source transfers one handle to the SDK per delivery. The SDK borrows it to pipeline and render consumers, awaits all work (including GPU completion), then calls release once. Owner release must be idempotent. The SDK queue holds at most one processing frame and one replacement candidate. Cancelled compute promises settle only after borrowed memory is safe; a transferred `PreparedFrame` must be explicitly released by its consumer.
- `TargetBundle` uses JSON arrays, a gray8 pyramid and an explicit descriptor type and length. `imageHashDomain` defaults to `encoded-image`; compiler gray8 inputs must mark `canonical-gray8`. The validator enforces structural bounds, not authenticity; the target compiler validates the supported algorithm and compiler and computes or verifies the content hash at its serialization boundary. A packed production format is not defined; descriptors are never converted silently.
- Tracking quality `spatialCoverage` is the inlier convex hull divided by the original-target area; predicted results are not successful observations. The SDK expires the overlay even with no new frames. Unknown calibration or physical size means null T and `poseMetricValid=false`. K is tied to the standard geometry; distortion treatment must be declared.
- A `FrameSource` promises source initialization; callbacks during start are released until ready. `start` must respond to its `AbortSignal`. `stop` quiesces callbacks; late deliveries are released. `VisionPipeline` process results bind both session and frame. A recognizer returns candidates; confirmation belongs to the tracking pipeline.
- `nowSessionUs` exposes the source session clock for `predictionExpiresAtUs` comparisons; it returns null without a running session. The SDK also subtracts processing and render latency from a receipt-clock deadline and never renews a deadline using predicted results. Generic adapters without a session clock get receipt-clock bounds only, not verified capture-age bounds.
- `RenderSink.setTargets` is optional size registration; `connectEvents` attaches typed media error and blocked events, returns an unsubscribe and preserves session isolation. The SDK owns disconnect during dispose. Unknown adapter exception text is not public diagnostic data.
- SDK `onDiagnostics` is opt-in and carries numeric and identity metadata only. CPU submission, result availability and render submission use the source session clock; GPU completion and visible time stay null when unmeasured. Candidate and stale drops are explicit. Callbacks cannot retain camera handles because none are exposed in that record. Event timestamps use the same source clock (a session-relative SDK clock if the source lacks `nowSessionUs`); after stop, the fallback preserves the most recent source offset.

## TypeScript / C++ / WGSL boundary

No browser object, JS number timestamp or opaque GPU resource crosses a native ABI implicitly. The boundary uses scalar u32 IDs, lengths and offsets, float32 point pairs (x,y), float32 row-major matrices and byte descriptors with explicit stride; timestamps remain JS float64 microseconds and are associated with job metadata. WebAssembly memory growth invalidates borrowed views, so copy or reacquire views after calls. WGSL matrices need an explicit transpose or row construction because native matrix layout differs.

`DeviceService` exposes only loss notification, generation and idle completion, never internal GPU buffers. The renderer uses an independent device and copies public CPU results. On device loss: cancel jobs, await safe completion, invalidate generations, hide, recreate the backend, reset tracking and resume acquisition. The SDK must never advertise a fallback algorithm as descriptor-compatible without adapter validation.

`ComputeBackend` details: `u8-exact` precision; `CpuImagePayload` carries view-relative `byteOffset` and `byteLength`, stride, encoding, premultiplication and input or standard space. `PreparedFrame` generation, level, scale, storage and preprocessing fields become required once a concrete backend supplies them. Each `buildPyramid` entry is a separately owned idempotent lease (including the base level), never an unowned alias. `trackPoints` may include per-point residuals and reasons. One operation is in flight per backend. Scalar JavaScript CPU is the integration path when no WebAssembly module is available; WebAssembly readiness is reported separately.

Additions to these contracts are opt-in; incompatible changes need a coordinated migration.
