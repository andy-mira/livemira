# LiveMira Demo

[English](README.md) | [简体中文](README.zh-CN.md)

公开引擎的全屏 Demo：把相机对准示例图片，图片上就会播放视频。

```sh
npm run dev   # 构建 dist/demo 并在 http://127.0.0.1:5173/ 提供
```

在手机上请通过 HTTPS 打开页面（例如用临时隧道连到本地服务）；相机需要安全上下文。点击**开始**，允许相机，并把相机对准所选图片（显示在另一块屏幕上或打印出来）。

面板（角落的圆形按钮）：**运行**（开始、停止、声音、重试视频）、**目标与视频**（示例图片或自己的图片；内置、本地或 HTTPS 视频）、**选项**（处理长边、相机画面填充、丢失后保留视频、取帧方式）、**可视化**（识别边框与匹配点）与**诊断**（完整日志开关与导出）。选项在下次开始时生效。默认值：处理长边 640、宽限 500 ms、canvas 取帧、相机画面铺满屏幕。

Demo 只使用公开引擎（运行时加载 `livemira-engine.mjs`），只有打开绘制时才加载 tracking visuals 模块。全部在设备本地运行，不上传任何内容。示例图片来源见 [CREDITS](assets/CREDITS.md)。
